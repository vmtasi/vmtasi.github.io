Model Knowledge

A note on the difference between what a model learns from data and what we assume about the world before modelling.

This is a working note. The site is intended to record ideas, experiments, questions, and conclusions as they develop rather than present only polished final results.

Missingness and the Observation Process

A recurring issue in the prospectivity workflow is the treatment of missing values. I initially treated missingness primarily as a preprocessing problem: observations with incomplete predictor values either had to be removed or the missing values had to be estimated. During the spatial analysis, however, it became clear that this interpretation is not always appropriate.

For a geospatial dataset, the observed data are not simply a representation of the physical system. They are also a representation of the observation process. The availability of a geological, structural, or geophysical variable can depend on where surveys were conducted, how the underlying feature was mapped, the resolution of the source dataset, historical exploration activity, or limitations in geological interpretation.

This distinction is particularly important for distance-based predictors. Suppose the variable

Df(x) = distance from location x to the nearest mapped fault

is unavailable at some locations. A missing value does not imply Df(x) = 0 nor does it imply that Df(x) is equal to the mean distance observed elsewhere. These represent different statements about the physical system.

A measured zero means that the observation lies on the mapped feature: Df(x) = 0. A missing value means that the value of Df(x) has not been established in the available data. These two states therefore should not be treated as equivalent.

The same problem occurs when a predictor is only available over part of a geological domain. If observations beyond a particular spatial extent have systematically missing structural information, conventional imputation can create an artificial continuation of the observed relationship. For example, if the available data suggest that mineralization probability declines with increasing fault distance, imputing missing distances based on the observed distribution implicitly assumes that the same structural relationship applies in the unobserved area.

That assumption may be precisely what the spatial analysis is supposed to test.

The issue can be expressed more formally by distinguishing the physical variable from its observation indicator. Let

Xj(x) denote the true, potentially unobserved value of predictor j at location x, and let

Rj(x) = { 1, if Xj(x) is observed; 0, if Xj(x) is missing }

The dataset therefore contains information about both Xj(x) and, potentially, the spatial distribution of Rj(x). If P(Rj(x)=1) varies systematically with location, tectonic domain, geological setting, or accessibility, then the missingness pattern itself contains information about the observation process.

This does not mean that every missing value should automatically be introduced into the prospectivity model as a predictor. That would require additional justification. The more immediate methodological requirement is to investigate whether missingness is spatially structured and whether it is concentrated in particular domains or portions of the study area.

This is especially relevant to spatial validation. If a predictor is well observed in the training regions but poorly observed in a withheld region, then the model's apparent predictive performance may partly reflect differences in data availability rather than differences in geological relationships.

The resulting principle for this project is therefore:

Missingness should be investigated before it is treated as a nuisance.

The dataset should be understood as having two components:

Observed geological information + the process through which that information became observed.

This distinction is important because the objective is not simply to produce a complete numerical matrix. The objective is to infer geological relationships that can be transferred to parts of the Copperbelt where the observation conditions may differ from those represented in the training data.

2026-08-13 — Why Spatial Validation Changes the Question

The transition from random cross-validation to spatial cross-validation was one of the more important methodological changes in the project.

For a conventional supervised-learning problem, the dataset can be represented as

𝒜 = {(Xi, yi)}i=1n, where Xi represents the predictors for observation i and yi represents the mineralization label.

Random k-fold cross-validation partitions these observations approximately at random:

𝒜 = 𝒜1 ∪ 𝒜2 ∪ ⋯ ∪ 𝒜k, with each fold being used as a test set while the remaining folds are used for training.

This procedure is reasonable when the objective is to estimate performance on observations drawn from the same underlying distribution. The problem is that the observations in this project are spatially located. Two nearby grid cells are not necessarily independent observations. They may share geological structure, lithology, geophysical characteristics, and spatially derived predictors.

Consequently, random splitting can produce a situation in which very similar environments occur on both sides of the training/test boundary.

The question being answered is then approximately:

How well does the model predict observations from a similar spatial distribution?

That is not necessarily the question required for mineral prospectivity mapping.

The more relevant question is:

Can relationships learned in one geographic region transfer to another geographic region?

This motivated the use of contiguous spatial blocks. If Bk represents a geographic block, the training and testing sets for fold k become

Dtrain(k) = D \ Bk and Dtest(k) = Bk. The model is therefore required to make predictions for an area that was spatially withheld during training.

This changes the interpretation of the AUC.

A random-CV AUC primarily measures discrimination under approximately the same sampling distribution. A spatial-CV AUC is a more demanding test of geographic transferability.

This became particularly important when examining the earlier models. V9 achieved an aggregate spatial AUC of approximately AUCV9 ≈ 0.693. Rather than interpreting this number only as a measure of model quality, I began examining the variation between individual spatial blocks.

For fold k,

AUCk = AUC(ytest(k), ptest(k)). The aggregate score can then be written as

̅AUC = (1/K) Σk=1K AUCk.

The individual AUCk values are important because a similar mean AUC can arise from two very different situations: either all folds have similar AUCs, or some folds perform much better than others. The second case indicates that predictive performance is spatially unstable.

This led to a change in the interpretation of poor-performing spatial blocks. A low AUC in one block does not automatically indicate that the model is simply inadequate. It can also indicate that the statistical relationship learned from the remaining geography does not transfer well into that particular region.

This is especially relevant to the distance variables.

A global logistic model might represent the effect of fault distance as

logit(pi) = α + βf Df,i + ⋯, which assumes that the same coefficient βf describes the relationship throughout the study area.

Introducing a quadratic term gives

logit(pi) = α + βf1 Zf,i + βf2 Zf,i2 + ⋯, where Zf,i = (Df,i − μf)/σf. This allows the relationship to be nonlinear, but it is still globally constrained if the same βf1 and βf2 apply everywhere.

The next step was therefore to allow these parameters to vary according to tectonic domain d:

logit(pi) = αd + βf1,d Zf,i + βf2,d Zf,i2 + ⋯. This is the conceptual basis of the V10/V11 heterogeneous model.

The turning point of the quadratic response occurs where ∂ηd/∂Zf = 0, giving

Zf* = −βf1,d / (2 βf2,d). Transforming this back into physical distance gives

Df* = μf + σf Zf*. This quantity is useful because it converts the statistical curvature into a physically interpretable spatial scale.

However, the spatially varying estimates also introduced a second question: are these domain-specific relationships actually supported by the data, or are they artifacts of limited observations in particular regions?

This is why spatial cross-validation is important for the heterogeneous model. The purpose is not merely to obtain a lower or higher AUC. It is to determine whether the estimated relationships survive geographic separation.

The resulting methodological progression is therefore:

Global linear relationship ↓ Global nonlinear relationship ↓ Domain-specific nonlinear relationships ↓ Spatial test of whether those relationships transfer.

The central hypothesis emerging from this process is not that every tectonic domain must have a different relationship. Rather, it is that spatial stationarity should be treated as an empirical question rather than assumed in advance.

If a single relationship performs consistently across spatial blocks, the simpler global model is supported. If performance and posterior relationships vary systematically between domains or geographic regions, then the evidence supports a more heterogeneous representation of the Copperbelt.
